# Taller Zabbix · CCOSS 2026

**De cero a Pull Request: tu primer template para Zabbix**

Repositorio de práctica del taller. Aquí abres tu primer Pull Request sin miedo a romper nada.

## Cómo participar

1. Haz **Fork** de este repositorio.
2. Crea la carpeta `participantes/<tu-usuario-github>/` con dos archivos:
   - `template_open_meteo_http.yaml`: tu template exportado desde Zabbix.
   - `README.md`: cómo se configura y qué macros tiene.
3. Abre un Pull Request hacia `main`.
4. Espera la **revisión automática** (pestaña *Checks*) y después la de los instructores.

La guía completa del taller está en [GUIA.md](GUIA.md).

## Estructura

```
referencia/      template completo de referencia (con dashboard) y su README
participantes/   una carpeta por participante
scripts/         la revisión automática que corre en cada PR
```

## Reglas

- Solo toca tu carpeta dentro de `participantes/`.
- Sé amable en los comentarios: todas y todos estamos aprendiendo. Aplica el [Código de Conducta de CCOSS](https://ccoss.org/coc/).

## ¿Y después?

Cuando tengas un template de algo que *no exista todavía*, envíalo al repositorio oficial de la comunidad: https://github.com/zabbix/community-templates
